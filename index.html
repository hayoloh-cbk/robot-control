Kontrol Micro:bit

Tahan tombol untuk bergerak, lepas untuk berhenti. Mengirim string up, down, left, right, dan stop saat tombol dilepas.

Tips: bisa juga pakai keyboard, yaitu ↑ ↓ ← → atau W A S D.

Capit

Klik sekali mengirim string capit atau lepas. Terakhir dikirim: -

Keyboard: C capit, L lepas

Terisi0
Kosong3

Klik slot untuk memasukkan mobil: sabot meluncur ke kamar peluru seperti tank sedang reload. Klik lagi untuk mengeluarkan mobil. Mengirim string masuk1\n–masuk3\n saat mobil masuk dan keluar1\n–keluar3\n saat mobil keluar atau slot sudah kosong.

Tips: pintasan keyboard 1 2 3 untuk slot parkir. Sensor infrared mengisi slot otomatis: micro:bit mengirim parkir1:1 saat mobil terdeteksi dan parkir1:0 saat mobil pergi. Lencana IR menyala hijau selama sensor mendeteksi.

Pin Micro:bit & Smart Parking

Kamera → Teachable Machine mengenali mobil → kelas parkir1–parkir3 / keluar1–keluar3 → slot di website terisi/kosong, lalu website mengirim masukN\n / keluarN\n ke micro:bit lewat Bluetooth. Sensor infrared di P1–P3 mengonfirmasi lewat parkirN:1 / parkirN:0.

PinSlotDari sensor IRKelas AIStatus
P1Parkir 1parkir1:1 / parkir1:0parkir1 masuk · keluar1 keluarKosongIR: belum ada data
P2Parkir 2parkir2:1 / parkir2:0parkir2 masuk · keluar2 keluarKosongIR: belum ada data
P3Parkir 3parkir3:1 / parkir3:0parkir3 masuk · keluar3 keluarKosongIR: belum ada data

Sensor IR: OUT ke P1/P2/P3, VCC ke 3V, GND ke GND. Di program micro:bit, led.enable(false) wajib karena P3 dipakai bersama layar LED. Saat melatih model di Teachable Machine, beri nama kelasnya persis seperti di tabel (huruf kecil, tanpa spasi). Website selalu mengirim masukN\n saat slot terisi dan keluarN\n saat kosong (N = 1–3), termasuk saat sensor IR melaporkan mobil datang atau pergi.
